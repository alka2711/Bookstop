BookStop – Buy, Sell & Rent Books
BookStop is a simple online bookstore where users can buy, sell, and rent books easily. It has a user-friendly design and helps book lovers connect with sellers.

Features
-Buy & Rent Books – Explore available books and get them easily
-Sell Books – Post ads for selling or renting books
-Search & Filter – Find books by name, category, or price
-Simple & Responsive UI – Easy to use for everyone

Tech Used
-Frontend: HTML, CSS, JavaScript
-Backend: Java (Spring Boot)
-Database: MySQL
